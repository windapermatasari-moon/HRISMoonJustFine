# MoonHR - Menu Bercabang

Versi ini menambahkan navigasi submenu internal pada dashboard admin.

## Cabang utama
- Organisasi: Departemen, Jabatan, Struktur
- Attendance: Rekap, Hari Ini, Terlambat, Izin & Sakit, Lembur, Monitoring Selfie
- Schedule: Kalender Jadwal, Template, Penugasan, Kelola Shift, Hari Libur
- Leave: Approval Inbox, Pengajuan Baru, Riwayat, Saldo Cuti, Jenis & Kebijakan
- Payroll: Periode, Proses, Register, Komponen, Lembur, Slip Gaji
- Talent: Performance, Penilaian, KPI, Lowongan, Pipeline Kandidat, Interview
- Reports: Analytics, Absensi, Payroll, Karyawan
- Settings: Perusahaan, Jam Kerja, Absensi, Cuti, Lembur, Payroll
- Roles: Daftar Role, Permission, User Access
- Audit: Semua Aktivitas, Login, Perubahan Data

## Catatan
Navigasi dan tampilan cabang sudah aktif. Modul transaksi yang belum tersambung ke database tetap memakai placeholder workflow sampai tabel dan operasi Supabase-nya dihubungkan.
